01 / QUICKSTART GUIDE

Tu primera petición en 60 segundos

Sigue estos 3 pasos para autenticarte y crear un pedido con código autogenerado ORD-YYYYMMDD-XXXXXX.

01

Obtén tu Token JWT

Inicia sesión en la pestaña Mis Pedidos o vía /api/v1/auth/login.

02

Envía el Header Authorization

Incluye tu token en la cabecera Authorization: Bearer <token>.

03

Ejecuta POST /api/v1/orders/

Envía el monto total_amount y recibe la orden validada con precisión decimal.

POST /api/v1/orders/ 
curl --request POST \
  --url 'http://localhost:8000/api/v1/orders/' \
  --header 'Authorization: Bearer <TU_TOKEN_JWT>' \
  --header 'Content-Type: application/json' \
  --data '{"total_amount": 250.50, "status": "PENDING"}'
const response = await fetch('/api/v1/orders/', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${localStorage.getItem('token')}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ total_amount: 250.50, status: 'PENDING' })
});
const order = await response.json();
console.log(order.order_code);
import httpx

response = httpx.post(
    "http://localhost:8000/api/v1/orders/",
    headers={"Authorization": "Bearer <TU_TOKEN_JWT>"},
    json={"total_amount": 250.50, "status": "PENDING"},
)
print(response.status_code, response.json())
